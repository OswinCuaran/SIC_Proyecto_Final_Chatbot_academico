#  Chatbot Académico - UNAL Manizales
## Administración de Sistemas Informáticos

---

## Descripción

Asistente virtual conversacional para consultar información académica del programa de Administración de Sistemas Informáticos de la Universidad Nacional de Colombia, sede Manizales. Desarrollado con tecnología RAG (Retrieval-Augmented Generation).

---

## Tecnologías

| Componente | Tecnología |
|------------|-----------|
| Backend | Python + Flask |
| Base de datos vectorial | ChromaDB |
| Embeddings | Sentence Transformers |
| LLM | GPT-3.5-turbo (OpenRouter) |
| Frontend | HTML + CSS + JavaScript |

---

## ¿Qué puede responder el chatbot?

- Materias por semestre
- Prerrequisitos de asignaturas
- Contenido de cada materia
- Créditos y tipología de asignaturas
- Información general de la malla curricular
